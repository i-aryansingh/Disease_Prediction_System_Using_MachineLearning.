Symptom-Based Disease Prediction System

Select the symptoms you are experiencing and get a preliminary, machine-learning-based list of possible conditions. Built with the Indian healthcare context in mind, where access to doctors can be limited in rural and remote areas.

Check Symptoms

Key features

Structured symptom selection

Search and pick symptoms from a fixed list. No accounts and no personal details required.

Random Forest prediction

A scikit-learn Random Forest model ranks possible diseases and returns up to the top three.

Transparent model information

The dashboard shows dataset size and evaluation metrics measured on held-out test data.

Works on any device

Responsive layout for desktop, laptop, tablet and mobile browsers.

How machine learning helps

The model is trained on a dataset where each row lists which symptoms are present for a known disease label. During training, a Random Forest builds many decision trees that learn which symptom combinations tend to go with which disease. When you submit symptoms, they are converted into the same present/absent format, and the trees vote. The share of votes for each disease is shown as a model-generated score. These scores are estimates, not medical probabilities.

Medical disclaimer: This system is for academic demonstration and preliminary information only. It cannot confirm any disease and is not a substitute for professional medical diagnosis. Consult a qualified healthcare professional for any health concern.
