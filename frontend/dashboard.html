    Prediction workflow

    1. You select symptoms from the structured list.
    2. The browser sends them as JSON to POST /api/predict.
    3. The backend validates the names and builds a present/absent vector in the training feature order.
    4. The Random Forest returns a score for every disease; the top three are sent back.
    5. The results page shows them with a disclaimer. Nothing is stored on the server.

    Symptom-Based Disease Prediction System – academic project. Predictions are preliminary and are not a substitute for professional medical diagnosis.
